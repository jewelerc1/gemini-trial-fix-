# הכל או כלום — מקור המשחק ל-Google AI Studio

המאגר הזה מכיל את גרסת ה-HTML המקורית של המשחק, לשימוש בתוך אפליקציית Android עם WebView.

## קבצים
- `index.html` — ממשק המשחק והלוגיקה המקוריים
- `board_scene.png` — תמונת הלוח
- `wheel_disc.png` — תמונת הגלגל
- `GEMINI_INSTRUCTIONS.md` — הוראות מדויקות ל-Gemini

## חשוב
אין לעצב מחדש את המשחק.
יש להשתמש ב-`index.html` כממשק המשחק המלא ולהציג אותו בתוך WebView.
